# Kumpulan Password & Akses Login

Berikut adalah daftar akun default yang telah dibuat untuk sistem HOT POT / HOT SUPPORT.

## 1. ISP / Admin (HOT SUPPORT)
**Role:** Super Admin / ISP
**Akses:** `/hotsupport`
- **Email:** `admin@hotsupport.com`
- **Password:** `password`

Admin ini memiliki akses untuk mengelola daftar Owner (RT/RW Net).

## 2. Owner (HOT POT)
**Role:** Pemilik RT/RW Net
**Akses:** `/` (Dashboard Utama)
- **Email:** `owner@hotpot.com`
- **Password:** `password`

Owner ini memiliki akses penuh ke manajemen MikroTik, Voucher, dan Pelanggan mereka sendiri.

## Catatan Penting
- Password "password" adalah default untuk development. Segera ubah password setelah sistem siap produksi.
- Untuk membuat akun baru, gunakan `tinker` atau fitur registrasi jika nanti ada.
